# Canale beta

Cartella manifest del canale beta: `zendate/beta/zendate.json`.

Non creare il manifest a mano: lancia `pubblica-update.bat` e scegli `2. beta`.
Lo script genera manifest + note, crea la Release come prerelease e pusha tutto.
Finché non pubblichi la prima beta, l'app mostra "Canale beta vuoto" (normale, non un errore).
