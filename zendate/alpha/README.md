# Canale alpha

Cartella manifest del canale alpha: `zendate/alpha/zendate.json`.

Non creare il manifest a mano: lancia `pubblica-update.bat` e scegli `3. alpha`.
Lo script genera manifest + note, crea la Release come prerelease e pusha tutto.
Finché non pubblichi la prima alpha, l'app mostra "Canale alpha vuoto" (normale, non un errore).
